# Magical Mirai 2026 Programming Contest Entry

初音ミク「マジカルミライ 2026」プログラミング・コンテスト 応募作品

> A lyric app created for the Hatsune Miku "Magical Mirai 2026" Programming Contest.

## Project Structure

```
├── src/
│   ├── index.html    # Entry point
│   ├── main.js       # TextAlive App API integration & core logic
│   └── style.css     # Styles
├── public/           # Static assets (images, fonts, etc.)
├── vite.config.js    # Build configuration (Vite)
└── package.json
```

## Setup

```bash
npm install
npm run dev      # Start dev server
npm run build    # Build for production → dist/
npm run preview  # Preview production build
```

## Technology

- [TextAlive App API](https://developer.textalive.jp/) — Lyrics synchronization
- [Vite](https://vitejs.dev/) — Build tool

## Designated Song

- **Answer Me** by imie (Grand Prize, Magical Mirai 2026 Song Contest)
